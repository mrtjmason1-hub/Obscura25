# Obscura25

A custom experimental cipher written in Python.

Obscura25 is a personal project exploring custom encryption through position-based shifting and a dynamic state variable.

## Features

- Custom alphabet
- Password-derived key
- Dynamic character shifting
- Position-dependent encryption
- Space and punctuation encoding
- Encryption and decryption modes

## How to use

1. Run `Obscura25.py` using Python.
2. Choose `e` to encrypt or `d` to decrypt.
3. Enter your message.
4. Enter your password.

## Disclaimer

Obscura25 is an experimental cipher made for fun and learning. It is not intended for protecting sensitive information or replacing established encryption standards.
